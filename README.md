# 🎬 Movie Recommender System

## 📌 Overview
This project is a Movie Recommendation System built using Machine Learning techniques.

## 🧠 Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn

## ⚙️ How it works
It uses similarity scoring (cosine similarity) to recommend movies based on user input.

## 📂 Files
- Movie_Recommender.ipynb → Main notebook

## 🚀 How to Run
1. Clone repo
2. Open notebook in Jupyter
3. Run all cells
